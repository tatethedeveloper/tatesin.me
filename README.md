# tatesin.me

Personal site of Tate Sinclair, software engineer. Built with Astro and
deployed to GitHub Pages. The structure in the hero is drawn from this
repository's own commit history, one strut per commit.

- `npm run dev` starts a dev server
- `npm run build` builds to `dist/`
- `npm run preview` serves the build

Everything still to be filled in renders as a visible `[ADD: ...]` placeholder
and is marked `TODO(tate)` in source: `grep -rn "TODO(tate)" src`.

The brief and working notes are in `CLAUDE.md`; the current design plan is in
`docs/design-plan.md` (v2), with the earlier direction kept in
`docs/design-plan-v1.md`.
