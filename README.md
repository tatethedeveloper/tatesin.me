# tatesin.me

Personal site of Tate Sinclair, software engineer. Built with Astro and
deployed to GitHub Pages. The structure at the top of the page is drawn from
this repository's own commit history.

- `npm run dev` starts a dev server
- `npm run build` builds to `dist/`
- `npm run preview` serves the build

The brief and working notes are in `CLAUDE.md`; the design plan is in
`docs/design-plan.md`.
